# Java_Projects_ASU
Contains several projects that were interesting from my Object-Oriented Programming and Data Structures class. Bank Application is a system that holds several bank accounts and can perform several actions on them, FoodBills is a server app project, similar to the ones seen on tablets built using Java's JFrame libraries,
Enhanced FoodBill is much better and prettier than FoodBill. TextReader works like Word's functionality in reading characters and words, focuses on I/O fundamentals and outputs the info in a new file. Recursive solutions include several recursive solutions, including an interesting triangle area problem. Scrabble is a program dealing with data structures, specifically stacks and queues.
